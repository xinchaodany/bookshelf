BOOKSHELF / TỦ SÁCH — offline app

Put these files on any free HTTPS host, open the address once in Chrome,
then choose "Install app". After that it works with no internet.

Easiest: GitHub Pages
 1. Create a free account at github.com, then a new public repository (e.g. "bookshelf").
 2. "Add file" > "Upload files" > drag in ALL files from this folder > Commit.
 3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root) > Save.
 4. Wait ~1 minute. Your app is at https://YOUR-NAME.github.io/bookshelf/

On Android (Chrome): open that address > menu (⋮) > "Install app" / "Add to Home screen".
Open it once while online so fonts get saved, then it works offline.

Updating: replace the files and change VERSION in sw.js (e.g. bookshelf-v2).
